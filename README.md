# Plant & Vegetable Health Detection

An image-classification web app that identifies plant diseases and vegetable freshness from photos.

## What it does
Upload a photo of a plant leaf or vegetable. The app reports:
- **Status / class** (e.g. "Tomato — Late Blight", "Fresh Banana", "Rotten Apple")
- **Confidence %** with a visual meter
- **Disease name** (where relevant)
- **Safe-to-consume verdict** (highlighted box — green = safe, orange = not safe)

> *Visual estimate from appearance only — not a food-safety test.*
