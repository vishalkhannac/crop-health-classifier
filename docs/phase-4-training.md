# Phase 4 — Training (multi-class)

**Objective:** train the model and save the training curves.

## Tasks
- [ ] Create `src/train.py`.
- [ ] Compile with **Adam** optimiser and **categorical cross-entropy** loss, tracking accuracy.
- [ ] Train for about **10 epochs** using the train and validation sets from Phase 2.
- [ ] Save the accuracy/loss curves as an image (e.g. `training_curves.png`).
- [ ] If training errors, fix it and re-run before continuing.

## Definition of done
Training completes, validation accuracy is reported per epoch, and the curves image is saved.

## When this phase is done
1. Tick Phase 4 in `todo.md` and note the final validation accuracy.
2. Update `HOW_TO_RUN.md` (how to train).
3. Commit: `git commit -m "Phase 4: multi-class training run"`.
